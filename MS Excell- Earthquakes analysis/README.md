
# South Asia Earthquake Analysis (2020–2025)

## Dataset
- Source: USGS Earthquake Catalog
- Records: 5410 earthquakes
- Region: South Asia
- Period: 2020–2025

## Data Cleaning
- Parsed date/time fields
- Created Year and MonthYear variables
- Verified missing values

## Key Findings

1. Most earthquakes have magnitudes between 4 and 5.
2. Approximately 60% of earthquakes occur at shallow depths (<23 km).
3. A weak negative correlation exists between depth and magnitude (r = -0.225).
4. Earthquake activity remained broadly stable from 2020–2025.
5. Earthquakes cluster along major tectonic boundaries in South Asia.
